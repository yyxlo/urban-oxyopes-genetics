# Urbanization and genetic diversity in *Oxyopes sertatus*

This repository contains the R code required to reproduce the main analyses and figures of the manuscript: Rapid urbanization reduces genetic diversity and increases genetic differentiation of a lynx spider _Oxyopes sertatus_ in central Taiwan.
Data available on Zenodo: [doi:10.5281/zenodo.18486231](https://doi.org/10.5281/zenodo.16932186)
